法人リサーチ AI Ver.1.0 / 歴代役員・関連法人調査

【既にCloudflareとGitHubを連携した方】
1. GitHubの corporate-research が Private であることを確認。
2. このZIPを展開し、README.txt、worker.mjs、wrangler.jsonc、publicフォルダの中身を、既存のリポジトリの同じ位置にアップロードしてコミット（上書き）。ZIP自体をアップロードしない。
3. wrangler.jsonc の name は Cloudflareの実際のWorker名に合わせる。この配布版は corporate-research に設定。既存名が corporate-research-ai ならその値だけ修正。
4. Cloudflareの自動ビルドが成功したことを確認。ビルドコマンドは空欄、デプロイコマンド npx wrangler deploy。PCへのインストール不要。
5. Workerの設定 > 変数とシークレットに、シークレットとして GEMINI_API_KEY、TAVILY_API_KEY と APP_PASSWORD を設定。APIキーはGoogle AI Studioの課金無効の無料プロジェクトから発行。パスワードは長いランダムな半角英数字。GitHubやチャットに貼らない。
6. WorkerのURLにアクセス。ユーザー名 owner / 設定したパスワード。APP_PASSWORD未設定時はアクセス拒否。旧URLがそのまま使用可能な場合あり。
7. サンプルで画面とExcel出力を試し、その後公開名簿1件でAPIテスト。会社の外部AI利用規定を確認。

【操作】
複数年のPDF、DOCX、XLSX、CSV、画像、TXTをまとめて選択し、公開資料確認にチェック、名簿を解析。資料を1件ずつ処理しSHA-256で同じファイルの再投入を防ぐ。途中保存済みなら次回同じ資料を選んでもスキップ。未処理ファイルは画面終了後は再選択が必要。
抽出結果・年度の修正を開き、法人名と地域の表記を揃える。年度を確認し、全員掲載の名簿であると確認できたものだけチェック。名簿の掲載年度と就退任日は別。同じ法人・地域・正規化氏名の暫定統合。異なる同姓同名は区別IDを入力して分離（同じ人の全年度に同じIDを設定）。表記揺れは手動修正。法人地域が違えば別グループになるため必要に応じて表記統一。氏名等を修正すると検索キーが変わるため再調査。前の検索結果はバックアップ内に残る場合がある。
未調査者を一括調査 / 選択した人を調査・再調査。1名ずつ処理（Tavily 2件、Gemini 1件）。地域と名簿役職・掲載年を手掛かりに検索。検索結果0件は候補未発見として保存し、APIエラー時は未調査のまま停止。無料枠制限では停止し続きから再開。再調査は当該人の結果を置換するため先にバックアップ推奨。停止は以降の処理を止めるが送信済みリクエストは消費されうる。
歴代役員 / 年度別・変遷 / 関連法人 / 法人相関図 / 情報ソース の各タブ。氏名・法人・役職で絞り込み、ランクで人物を絞り込み。法人候補は法人番号または名前と所在地で統合、D判定は営業候補から除外。営業状態・優先度は手動設定。個別詳細でランク修正・確認済み・メモ。判定は全て暫定であり、Sも本人確認を保証しない。AI提示URLと検索メタデータの根拠候補を区別。検索抜粋で氏名・法人名・根拠が一致しなければC、AIによる自動判定は最大B。A・Sは原典確認後に手動で変更。URLを開いて内容・時点・人物を確認。
Excelは6シート、CSVは人物法人関係。Excelの表は文字列として出力。バックアップJSONで別端末へ移行。データは端末のlocalStorage（容量制限あり）で、同期なし。会社PC等で共有ブラウザを使わない。バックアップは機密管理し、GitHubに入れない。

【制限】
1ファイル8MB、Office XMLの抽出テキスト50万文字。旧DOC/XLS、暗号化、埋込画像、複雑な書式は未対応。画像化したWord/ExcelはPDF等に変換。Office解析およびExcel作成は外部CDNのfflate 0.8.2を使用（CDNアクセスが会社で禁止されると利用不可）。ブラウザでの元資料解析とAIへの送信を行う。クラウド上に履歴は保存しない。モデルは gemini-3.5-flash-lite 固定。検索は Tavily basic（1名につき2リクエスト）。接続テストはGemini・Tavily各1リクエストを消費。Tavilyも無料プラン・追加課金無効で使用すること。無料枠をアプリが独自に保証・検知するわけではない。課金無効のプロジェクトを使用すること。429等で停止。有料モデルへの自動切替なし。無料APIデータ利用条件により公開資料のみ。個人の自宅・私的連絡先は対象外。

【地域特定・検索精度修正版（Ver.1.0）】
既存の3シークレットはそのまま。更新前にアプリのバックアップを取得し、GitHubの同じ位置へ上書き。Cloudflareのデプロイ完了後、Ctrl+F5。
新規解析完了時、選択中の法人の基本情報候補を自動検索。既存の名簿は「法人情報をWEB検索」で候補を表示。出典を開き、対象法人を確認して採用。候補が出ない場合、出典一覧を確認し、都道府県・市区町村等を手動保存。法人番号・住所は出典で裏付けられる範囲。人物調査前に所在地を確定すること。旧結果は残し、地域が変わった結果は一括調査の再対象。関連法人候補は一覧で法人名・役職・暫定ランク・出典を確認。法人ごとに基本検索2回、人物ごとに最大4回。502/503/504は各通信最大2回再試行、429等の無料枠制限は再試行せず停止。検索回数が増えるため無料枠を消費する。API側課金は無効のまま。法人情報の確定は選択中の法人単位。名称・地域表記の異なる名簿は従来どおり抽出結果で統一する必要あり。実際のAPI応答とiPad実機は未検証。
